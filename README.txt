自動建値の推奨初期設定（Exness ZERO）
- 自動建値：OFF（検証時にON）
- 建値発動：1.5 pips（バックテストでは1.0／1.5／2.0を比較）

既存口座をスマホへ再接続する（接続キー.txt不要）
1. 同梱の最新版EAをMetaEditorでF7コンパイルし、接続済みのMT4／MT5チャートへ付け直します。
2. EAチャート上の黄色い「スマホ再接続」ボタンを押します。
3. チャートに表示された6桁コードを、PWAの「メニュー」→「接続設定」へ入力します。
4. 「6桁で接続」を押すと、口座名・ブローカー・口座番号が自動でプルダウンへ登録されます。
5. EAは新しい接続キーを自動保存して接続を再開します。スマホへファイルを送る必要はありません。

※「スマホ再接続」ボタンは既存の接続キーを持つデモ口座用です。実口座では動作しません。

MT4導入の要点
- MT4の「ファイル」→「データフォルダを開く」→ `MQL4\Experts` へ `TOM_FX_Zero_Reader.mq4` をコピーし、MetaEditorでF7コンパイルします。
- EAを任意のチャートへ1つ設定し、初回はチャートに表示された6桁コードをPWAの接続設定へ入力します。既存接続の復元はチャートの「スマホ再接続」ボタンを使用します。EAはMT4のログイン口座からブローカー・サーバー・口座番号を自動取得します。
- 接続キー.txtを使う場合はMT4の `MQL4\Files` へコピーします。MT5のキーとは同じ形式ですが、口座ごとにPWAの接続プロファイルを分けてください。
- MT4の「ツール」→「オプション」→「エキスパートアドバイザ」で `https://tom-fx-zero.ryuichi512.chatgpt.site` をWebRequest許可URLへ追加します。
- MT4を4台使う場合はPWAの「口座を管理」からMT4デモ口座を4つまで追加し、各MT4で別々にペアリングします。

週末BTCテストの手順（必ずデモ口座）

1. 同梱の TOM_FX_Zero_Reader.mq5 をMetaEditorでF7コンパイルし、MT5チャートへ付け直します。
2. EAの「週末BTCテスト設定」→「BTCUSDをPWAの週末テスト用に許可」を true にします。銘柄名は通常 BTCUSDz のままで構いません。ブローカー側の名称が異なる場合だけ「週末テスト銘柄」を変更します。
3. PWAのゴトー日画面で「週末BTCテストを有効化」にチェックします。BTCが通貨ペア欄に出たら選択します。
4. まず0.01 lotで、チャート・現在価格・BUY／SELL・決済を確認します。実口座・コンテスト口座では従来どおり注文・決済は拒否されます。
5. テスト終了後はPWAのチェックを外し、EAのBTC許可も false に戻します。

追加通貨ペアの設定

1. EAの「銘柄・チャート設定」で「追加取引銘柄1〜3」にMT5に表示される銘柄名を入力します。例：GBPAUDz、GBPJPYz、AUDJPYz。
2. F7コンパイル後、EAをチャートへ付け直します。未検出時は、AutoDetectBrokerSymbols=trueなら通貨ペア本体（例：GBPAUD）から接尾辞を自動探索します。
3. PWAを更新すると、ゴトー日の通貨ペア欄に「GBP/AUD（GBPAUDz）」のように表示されます。

Windows Server 2019 VPSの自動起動・再起動
1. ZIPの `vps` フォルダをWindows VPSへ展開します。
2. 自動ログオンに使うWindowsユーザー（通常はAdministrator）でログインし、`TOM_FX_Zero_VPS_Setup.bat`を管理者として実行します。
3. MT4の `terminal.exe` とMT5の `terminal64.exe` のパスを入力します。未インストールの端末は空欄で構いません。
4. PWAの「接続設定」にある同じConnectionKeyを入力します。BATはキーをDPAPI暗号化して保存します。
5. Windows自動ログオンをSysinternals Autologonで設定します。パスワードはAutologon自身へ入力し、TOM FX ZEROへ渡さないでください。
6. まず手動で1回再起動し、MT4／MT5、EA、PWAのリアルタイム接続が復旧することを確認します。
7. 以後はPWAの「VPSを再起動」から、確認画面を経て再起動指示を送信できます。再起動は約30秒後に実行されます。

注意：VPSがオフライン、Windows自動ログオンに失敗、またはエージェントが停止している場合はPWAから再起動できません。その場合はVPSプロバイダの管理画面またはRDPで復旧してください。ブローカー側に保持されたTP／SLは通常VPS再起動で消えませんが、復旧後に必ずMT4／MT5で確認してください。

導入手順（PC）
1. ZIPをダウンロードして展開します。既存のMT5フォルダを丸ごと置き換えないでください。
2. ExnessのMT5を起動し、照合する口座にログインします。
3. 「ファイル」→「データフォルダを開く」→ MQL5 → Experts を開きます。
4. mt5フォルダの TOM_FX_Zero_Reader.mq5 だけを Experts にコピーします。
5. MT5でF4を押してMetaEditorを開き、コピーしたmq5を開いてF7でコンパイルします。
6. エラーが0件になったことを確認。エラーが出た場合は一覧のスクリーンショットで確認します。
7. MT5のナビゲータの「エキスパートアドバイザ」を右クリック→更新します。
8. 他のEAを動かしていない新しいチャートを1枚開き、本EAをドラッグします。
9. まずAllowDemoClose=falseのまま取り付けます。DLLは不要です。リアルタイム接続を使わない場合はWebRequest許可も不要です。
10. チャートに READ ONLY と出力時刻が表示されます。
11. 「ファイル」→「データフォルダを開く」→ MQL5 → Files に
    TOM_FX_Zero_snapshot.json が作成されます（既定10秒ごとに更新）。
12. 確認画面の「MT5出力ファイルを選ぶ」でJSONを選びます。
    PCでは同じ画面、スマホではそのJSONを自分の端末へ転送して読み込みます。
    0.3.1では、次の手順でスマホへ自動同期することもできます。

デモ決済エンジンのテスト

安全制限
・実口座とコンテスト口座では、リアルタイム送信とAllowDemoCloseによる決済をコード側で拒否します。
・リアルタイムAPIもtradeMode=demo以外を拒否します。
・接続キーは第三者へ共有しないでください。漏えいした場合はPWAの「接続キーを作り直す」を使用してください。
・指示ファイルの口座番号がMT5口座と違う場合は拒否します。
・指示作成から5分、またはスナップショット取得から指示作成まで5分を超えると拒否します。
・選択した全チケットが決済前に存在することを確認してから処理します。
・決済は同期方式で1件ずつ実行し、各チケットの結果コードを結果ファイルへ残します。
・ブラウザが同名ファイルへ(1)などを付けた場合は、TOM_FX_Zero_close.txtへ戻してからコピーします。

1. まず一部決済のない既存ポジションを選びます。検証のために実口座へ新規注文する必要はありません。
2. MT5の履歴を全期間にし、該当ポジションの新規約定にある手数料を確認します。
3. ツールの手数料と一致するか確認。スワップ・売買損益は取得時刻を揃えて比較します。
4. 新規時手数料が往復分か、実際の口座履歴でも照合してください。

6. 「手数料取得済」はMT5の約定履歴から手数料を取得できたことを示します。

計算
純損益＝現在の売買損益＋未決済分スワップ＋残数量対応の新規手数料＋残数量対応の新規費用。
APIの費用は通常マイナスの符号付き値なので、そのまま加算します。
既に売買損益へ反映されたスプレッドや、新規時に徴収済みの往復手数料を二重控除しません。
一部決済では直前の残数量に対する決済数量の割合で新規費用を配分します。
決済済み部分の約定損益・スワップ・決済費用は未決済の合計へ含めません。
ポジション全体のライフサイクル損益や口座残高増減は、この未決済分合計とは異なります。

制限
ヘッジ口座のIN/OUT/OUT_BY履歴を対象。ネット口座、反転、数量不整合、ゼロ手数料、
非売買の関連約定や順序不整合は未確認として保守的に扱います。
ポジションに紐付かない口座単位の手数料・調整・リベートは配分しません。
通貨は3文字の口座通貨コードを想定。金額は計算中に丸めず、表示時のみ丸めます。
取得中の価格変動により各行は完全に同じ瞬間の価格ではありません。
ファイル作成時刻はPC時計を用いるため、PC時刻を正しく設定してください。
履歴の保存範囲や記録形式により追加対応が必要になる場合があります。
